# Google / SEO

Esta carpeta sirve para organizar documentación y materiales auxiliares relacionados con Google.

**Importante:** `robots.txt` y `sitemap.xml` no deben moverse a esta carpeta. Los buscadores deben encontrarlos en la raíz pública del sitio:

- `https://jomaluna02.github.io/lunastore/robots.txt`
- `https://jomaluna02.github.io/lunastore/sitemap.xml`

Google Tag Manager y Google Analytics se cargan desde `index.html` porque son integraciones de la página y no archivos que Google pueda leer desde una carpeta del repositorio.
